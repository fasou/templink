🔧 技术实现

加密过程（JavaScript）：

// 1. 创建链接数据对象 const linkData = { id: "abc123", target: "https://example.com", expiry: 1678886400000, created: 1678800000000 }; // 2. 转换为JSON字符串 const dataString = JSON.stringify(linkData); // 3. URL编码 + base64编码 const encodedData = btoa(encodeURIComponent(dataString)); // 4. 生成最终URL const finalUrl = `https://fasou.github.io/templink/redirect.html?data=${encodedData}`;

解密过程（JavaScript）：

// 1. 从URL获取加密数据 const encodedData = new URLSearchParams(window.location.search).get('data'); // 2. base64解码 + URL解码 const decodedString = decodeURIComponent(atob(encodedData)); // 3. 解析JSON数据 const linkData = JSON.parse(decodedString); // 4. 使用数据 console.log("目标URL:", linkData.target); console.log("过期时间:", linkData.expiry);

✅ 加密功能特点

  • ✓ 隐藏敏感信息：目标URL、过期时间等参数不再明文显示
  • ✓ 简单有效：base64编码虽然不是强加密，但能有效隐藏URL参数
  • ✓ 浏览器原生支持：使用JavaScript内置的btoa()/atob()函数
  • ✓ 向后兼容：系统同时支持加密和未加密的URL格式
  • ✓ URL安全：编码结果只包含URL安全字符
  • ✓ 性能优秀：编码解码速度快，不影响用户体验
