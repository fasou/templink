# TempLink - 临时链接生成器

一个免费的临时链接生成和分享系统，支持48小时有效期的跳转链接，并具有分享继承剩余时间的功能。

## ✨ 功能特性

- **临时跳转链接**：创建短链接，点击后跳转到目标网页
- **48小时时效**：链接在首次打开后的48小时内有效
- **时间继承分享**：被分享的链接继承原始链接的剩余时间
- **免费托管**：基于静态文件，可部署在任意免费托管平台
- **二维码生成**：自动生成链接二维码，方便移动端分享
- **统计信息**：显示链接创建时间、访问次数和剩余时间

## 📖 使用说明

### 1. 创建临时链接
1. 访问主页面
2. 输入目标网址（必须以 http:// 或 https:// 开头）
3. （可选）自定义短链接标识
4. 点击"生成临时链接"

### 2. 分享链接
1. 生成链接后，点击"生成分享链接"按钮
2. 系统会自动生成一个继承剩余时间的分享链接
3. 复制链接分享给其他人

### 3. 链接跳转
1. 任何人点击链接都会进入跳转页面
2. 3秒倒计时后自动跳转到目标页面
3. 页面显示链接剩余时间和访问统计

## 🔧 技术实现

### 核心功能
- **链接存储**：使用浏览器 localStorage 存储链接数据
- **时效管理**：基于时间戳计算48小时有效期
- **分享继承**：分享链接继承原始链接的剩余时间
- **客户端跳转**：完全在前端实现跳转逻辑

## 📋 技术细节

### 链接数据格式
```javascript
{
  "targetUrl": "https://example.com",  // 目标网址
  "expiry": 1678886400000,            // 过期时间戳（48小时后）
  "created": 1678800000000,           // 创建时间戳
  "clicks": 3,                        // 访问次数
  "sharedFrom": "abc123"              // 分享来源（可选）
}
```

### 链接URL格式
- 原始链接：`https://your-domain.com/redirect.html?id=abc123`
- 分享链接：`https://your-domain.com/redirect.html?id=abc123_share_def456`

### 时效性规则
1. 原始链接：从创建时间开始计算48小时
2. 分享链接：继承原始链接的剩余时间
3. 所有链接在过期后无法访问
4. 时间计算基于客户端本地时间
