# 2026-03-14 TempLink 项目开发记录

## 🎯 项目概要
为用户创建一个具有48小时时效性的临时链接分享系统，支持链接跳转和分享继承剩余时间功能。

## 📋 需求分析
用户需求：
1. 链接打开后跳转到另一个网页
2. 原链接被打开后48小时失效
3. 分享给他人时，被分享的链接继续按照剩余时间倒计时
4. 链接能免费托管

## 🏗️ 技术方案设计
1. **架构选择**：纯前端静态网页应用
2. **数据存储**：浏览器localStorage存储链接数据
3. **时间管理**：基于时间戳的48小时倒计时
4. **分享机制**：分享链接继承原始链接剩余时间
5. **托管方案**：GitHub Pages、Vercel、Netlify

## 🔧 技术实现细节

### 核心算法
```javascript
// 时效性计算
剩余时间 = 创建时间 + 48小时 - 当前时间

// 分享链接生成
分享链接ID = 原始ID + "_share_" + 随机ID
分享链接过期时间 = 原始链接过期时间
```

### 数据存储结构
```json
{
  "targetUrl": "https://example.com",
  "expiry": 1678886400000,
  "created": 1678800000000,
  "clicks": 3,
  "sharedFrom": "abc123" // 可选，表示分享来源
}
```

### 链接URL格式
- 原始链接：`/redirect.html?id=abc123`
- 分享链接：`/redirect.html?id=abc123_share_def456`
