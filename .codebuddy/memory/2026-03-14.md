# 2026-03-14 TempLink 项目开发记录

## 🎯 项目概要
为用户创建一个具有48小时时效性的临时链接分享系统，支持链接跳转和分享继承剩余时间功能。

## 📋 需求分析
用户需求：
1. 链接打开后跳转到另一个网页
2. 原链接被打开后48小时失效
3. 分享给他人时，被分享的链接继续按照剩余时间倒计时
4. 链接能免费托管

## 🏗️ 技术方案设计
1. **架构选择**：纯前端静态网页应用
2. **数据存储**：浏览器localStorage存储链接数据
3. **时间管理**：基于时间戳的48小时倒计时
4. **分享机制**：分享链接继承原始链接剩余时间
5. **托管方案**：GitHub Pages、Vercel、Netlify

## 🔧 重要修复记录

### 2026-03-14 15:10: 修复跳转页面卡住问题
**问题描述**：生成的临时链接访问后卡在跳转页面无法正常工作
**根本原因**：GitHub Pages部署时，不同页面间的localStorage不共享（跨域/跨页面问题）
**解决方案**：通过URL参数传递所有必要数据，不再依赖localStorage跨页面读取

### 修复细节：
1. **链接生成**：修改 `app.js` 的 `generateLink()` 方法，生成包含完整参数的URL：
   ```
   /redirect.html?id=link123&target=https%3A//example.com&expiry=1678886400000&created=1678800000000
   ```

2. **跳转处理**：修改 `redirect.js` 的 `loadLinkData()` 方法：
   - 优先从URL参数读取 `target`、`expiry`、`created` 数据
   - 保持向后兼容，支持从localStorage读取

3. **分享功能**：更新 `app.js` 和 `redirect.js` 中的分享逻辑，生成包含完整参数的分享链接

4. **隐私改进**：根据用户要求，移除跳转页面上的目标URL显示

### 技术原理：
- **之前**：依赖 `localStorage` 存储数据，跳转页面通过 `linkId` 从 `localStorage` 读取
- **现在**：所有数据通过URL参数传递，跳转页面直接从URL参数解析
- **优势**：解决跨页面存储问题，提高兼容性，简化数据传递

## 🔐 2026-03-14 15:20: 添加URL参数加密功能

### 功能需求：
用户要求对生成的跳转链接进行简单加密，不要明文显示URL参数

### 实现方案：
使用base64编码对URL参数进行简单加密隐藏

### 加密实现细节：
1. **数据序列化**：将链接数据（id、target、expiry、created、shared）序列化为JSON字符串
2. **双重编码**：先使用 `encodeURIComponent()` 进行URL编码，再使用 `btoa()` 进行base64编码
3. **单一参数**：所有数据封装在单个 `data` URL参数中

```

```

- **之后**：`/redirect.html?data=JTdCJTIyaWQlMjIlM0ElMjAlMjJhYmMxMjMlMjIlMkMlMjAlMjJ0YXJnZXQlMjIlM0ElMjAlMjJodHRwcyUzQSUyRiUyRmV4YW1wbGUuY29tJTIyJTJDJTIwJTIyZXhwaXJ5JTIyJTNBJTIwMTY3ODg4NjQwMDAwMCUyQyUyMCUyMmNyZWF0ZWQlMjIlM0ElMjAxNjc4ODgwMDAwMDAwJTdE`

### 技术特点：
1. **简单有效**：base64编码虽然不是强加密，但能有效隐藏URL参数明文
2. **浏览器原生支持**：使用 `btoa()` 和 `atob()` 函数，无需外部库
3. **向后兼容**：系统同时支持加密和未加密的URL格式
4. **URL安全**：base64编码结果不包含特殊字符，对URL友好
5. **性能优秀**：编码解码速度快，不影响用户体验

### 代码修改：
1. **app.js**：`generateLink()` 和 `generateShareLink()` 方法
   - 将链接数据编码为JSON
   - 使用 `btoa(encodeURIComponent(data))` 进行编码
   - 生成包含 `data` 参数的URL

2. **redirect.js**：`loadLinkData()` 和 `copyShareLink()` 方法
   - 优先读取 `data` 参数
   - 使用 `decodeURIComponent(atob(data))` 进行解码
   - 保持对未加密URL的向后兼容
