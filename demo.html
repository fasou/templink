🚀 快速部署

GitHub Pages（推荐）

# 创建GitHub仓库
# 上传所有文件到main分支
# 在 Settings > Pages 中启用GitHub Pages
# 访问 https://你的用户名.github.io/仓库名

Vercel（一键部署）

# 安装Vercel CLI
npm install -g vercel

# 部署到生产环境
vercel --prod

Netlify（拖拽部署）

直接拖拽项目文件夹到 Netlify 网站即可完成部署
